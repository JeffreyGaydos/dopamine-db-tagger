The generator will create a playlist using everything after the first FROM in your query, so be careful not to include any logic in the SELECT columns themselves.

A note on date values in the Dopamine database

Dopamine stores dates as the C# tick value. SQLite does not have a built-in way to easily convert these values to human readable dates. As such, a custom "macro" has been included that can convert to and from the C# tick format and a readable date time.

Syntax:

  • @d('2026-12-31 14:30:02')
    will convert to the C# tick equivallent value that Dopamine uses (useful for sorting/filtering): 
    639343242020000000
  • @d(636586976464610048)
    will convert to a human readable string. Note that this string is NOT sortable: 
    2018-04-07 11:34:06

The exact code that runs these macros is as follows:

  • Convert Dopamine C# Ticks to Human Readable Date: 
    DATETIME(((@DopamineDateValue - 621355968000000000) / 10000000), 'unixepoch')
  • Convert Human Readable Date to Dopamine C# Ticks: 
    CAST(STRFTIME('%s', @HumanReadableDateString) AS INT) * 10000000 + 621355968000000000
